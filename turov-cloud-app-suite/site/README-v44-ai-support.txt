Turov Cloud v44 — AI Support Assistant

Добавлено:
- Кнопка ✨ ИИ-помощник в чате поддержки.
- Если в поле есть текст — он отправляется в чат, потом ИИ отвечает.
- Если ключ не указан — сайт не ломается, появится подсказка.

Куда вставить API-ключ:
1. В папке проекта выполни: cp .env.example .env
2. Открой: nano .env
3. Вставь ключ сюда: AI_API_KEY=...
4. Перезапусти проект: pm2 restart all или npm start

Модель можно поменять тут: AI_MODEL=openrouter/auto
Ключ хранится только на сервере, не в HTML.
