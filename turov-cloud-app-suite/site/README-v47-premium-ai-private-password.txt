Turov Cloud v47

Что добавлено:
- ИИ-помощник теперь доступен только пользователям с активным Premium.
- Если Premium нет, кнопка ИИ открывает красивое окно покупки Premium.
- Системный промпт ИИ усилен: ответы более практичные, пошаговые, только по-русски и без странных английских концовок.
- Приватные файлы теперь требуют пароль при загрузке.
- Приватный файл по ссылке открывается только владельцу/админу и дополнительно требует пароль перед скачиванием.
- В Premium-модалке добавлена функция «Умный ИИ-агент».
- Анимация удаления стала плавнее: появление, мягкое свечение, затухание и исчезновение карточки.

Ключ ИИ по-прежнему вставляется в .env:
AI_API_KEY=твой_OpenRouter_ключ

После замены файлов перезапустить сервер:
pm2 restart all
