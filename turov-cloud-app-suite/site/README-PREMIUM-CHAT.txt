Turov Cloud v40 — Premium Support Chat

Что улучшено:
- премиумное окно поддержки справа на ПК и fullscreen на телефоне;
- аватарки у сообщений: Пользователь / Поддержка;
- ник над сообщением и время под сообщением;
- Telegram-like bubbles, blur, glow, плавные анимации;
- вместо скрепки — кнопка с 👀;
- drag & drop: можно перетащить файл прямо в чат, появляется красивая подсказка;
- сохранена текущая серверная логика сообщений и вложений.

Запуск:
1) npm install
2) npm start

Если ставишь на VPS поверх старой версии: перед заменой сделай backup папки data и uploads/support_uploads.
