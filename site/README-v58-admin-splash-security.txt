Turov Cloud v58

Что исправлено:
- В админке стартовый preloader теперь показывается один раз за сессию, как на основном сайте.
- Автообновление админки больше не запускает чёрный экран с логотипом каждую перезагрузку.
- Добавлены базовые security headers.
- Cookie сессии усилены: httpOnly + SameSite=Lax, secure включается в NODE_ENV=production.
- Доступ к файлам дополнительно использует безопасный путь через basename, чтобы исключить path traversal.

Проверка приватных файлов:
- Приватный файл открывается только владельцу или админу.
- Если у приватного файла есть пароль, без ввода пароля открыть/скачать нельзя.
- Чужой пользователь по ссылке отправляется на вход и не получает доступ к файлу.
